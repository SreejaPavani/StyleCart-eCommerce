# StyleCart 👗

Full-stack e-commerce web app built with Python Flask and TiDB Cloud MySQL.

🔗 **Live:** [https://stylecart-ecommerce.onrender.com/](https://stylecart-ecommerce.onrender.com/)

---

* **Catalog & Cart:** Search, filter, sort, and session-based cart.
* **Auth & Admin:** User login/registration[cite: 1, 2], role-based access[cite: 8], and inventory/order dashboard[cite: 4, 6, 7].
* **Stack:** Flask, Bootstrap 5, TiDB Cloud, Render.
